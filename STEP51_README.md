# Step 51 — UI foundation

The existing Python engine and its custom JSON catalogues are unchanged. A new `frontend/` React/TypeScript/Vite app provides a premium industrial-maritime theme, a clickable illustrated island, and a searchable card library using the four custom decks.

Run: `cd frontend && npm install && npm run dev`

This is a UI prototype, not a playable connected game. See `frontend/README.md` for the integration boundary.
